# Chandu Spidey Portfolio — Minimal Redesign

This version keeps the Spider-Man/web interaction but uses a cleaner white, black and red layout inspired by the screenshots supplied in the conversation.

## Run
In this folder:
```bash
python -m http.server 5500
```
Then open:
http://localhost:5500

## Included
- `index.html` — portfolio content and sections
- `assets/css/style.css` — minimalist visual design
- `assets/js/script.js` — web shooter + GSAP scroll entrances
- `assets/img/chandu-profile.jpg` — supplied profile photo
- `assets/docs/Chandu-Resume.pdf` — supplied resume

The LinkedIn button uses the profile URL supplied in the conversation.
